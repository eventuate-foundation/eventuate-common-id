= Eventuate Common ID

image::https://eventuate.io/i/logo.gif[]

This project is part of http://eventuate.io[Eventuate], which is a microservices collaboration platform.

It contains the ID generation that the other Eventuate projects use: `IdGenerator`, which produces 128-bit `Int128` IDs, either generated by the application or by the database.

It publishes these artifacts under the group `io.eventuate.common.id`:

|===
| Artifact | Package | Contents

| `eventuate-common-id`
| `io.eventuate.common.id`
| `IdGenerator`, `ApplicationIdGenerator`, `DatabaseIdGenerator` and `Int128`

| `eventuate-common-spring-id`
| `io.eventuate.common.id.spring`
| `IdGeneratorConfiguration`, the Spring configuration that selects the `IdGenerator` with the `eventuate.outbox.id` property

| `eventuate-common-id-bom`
|
| The BOM for these artifacts
|===

Its version is set in a consumer's `gradle.properties` with the property `eventuateCommonIdVersion`.

== Migrating from eventuate-common

These modules were previously published by https://github.com/eventuate-foundation/eventuate-common[eventuate-common] under the group `io.eventuate.common`, and `eventuate-common-spring-id` was in the package `io.eventuate.common.spring.id`.
Each module declares the capability of its old coordinates, so a Gradle build that gets both the old and the new artifact fails with a capability conflict.

The https://github.com/cer/openrewrite-recipes/blob/master/eventuate-common-split/README.adoc[migration guide] lists the new groups, version properties and packages, and describes the OpenRewrite recipe that migrates a consumer.
